# AGENTS.md

## What this is

Published npm package (`react-touch-drag-slider`). Single default-exported React component in `src/lib/Slider.tsx`. Vite library build, outputs ESM + UMD to `dist/`.

## Commands

- `pnpm dev` — Vite dev server with demo app (http://localhost:5173)
- `pnpm build` — `tsc && vite build` (typecheck first, then bundle to `dist/`)
- `pnpm test` — vitest (watch mode by default)
- `pnpm lint` — `biome lint src/**/*.{ts,tsx}`

No `typecheck` script exists. Type checking happens as part of `pnpm build` (the `tsc` step). To typecheck without building: `npx tsc --noEmit`.

## Code style (Biome)

Single quotes, no semicolons, 2-space indent, trailing commas (es5). See `biome.json`.

## Source layout

- `src/lib/` — the published library (entry: `src/lib/index.ts` → re-exports `Slider`)
- `src/App.tsx`, `src/images.ts`, `src/style.css` — demo app (not published, lives in repo only)
- `src/utils.ts` — `getElementDimensions` helper (has inline vitest test via `import.meta.vitest`)

## Build notes

- `vite.config.ts` externalizes `react`, `react-dom`, and `styled-components` (the last is unused but still configured)
- Types generated by `vite-plugin-dts` into `dist/lib/index.d.ts`
- `"files": ["dist"]` in package.json — only `dist/` ships to npm

## Testing

- Single snapshot test in `src/lib/Slider.test.tsx` (renders Slider with images)
- Vitest configured inline in `vite.config.ts` with `jsdom` environment
- No interaction/drag tests exist

## Gotchas

- React peer dep is pinned to `^19.1.1` — narrow, will warn on React 18
- No CI workflow exists (`.github/` only has `FUNDING.yml`)
- `tsconfig.json` uses `moduleResolution: "Node"` — not `"Bundler"`, which would be more accurate for Vite
