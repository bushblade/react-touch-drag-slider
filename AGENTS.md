# AGENTS.md

## What this is

Published npm package (`react-touch-drag-slider`). Single default-exported React component in `src/lib/Slider.tsx`. Vite library build, outputs ESM to `dist/`.

## Commands

- `pnpm dev` — Vite dev server with demo app (http://localhost:5173)
- `pnpm build` — `tsc && vite build` (typecheck first, then bundle to `dist/`)
- `pnpm test` — vitest (watch mode by default)
- `pnpm lint` — `biome lint src/**/*.{ts,tsx}`

No `typecheck` script exists. Type checking happens as part of `pnpm build` (the `tsc` step). To typecheck without building: `npx tsc --noEmit`.

## Code style (Biome)

Single quotes, no semicolons, 2-space indent, trailing commas (es5). See `biome.json`.

## Source layout

- `src/lib/` — the published library (entry: `src/lib/index.ts` → re-exports `Slider`)
- `src/App.tsx`, `src/images.ts`, `src/style.css` — demo app (not published, lives in repo only)
- `src/utils.ts` — `getElementDimensions` helper (tested in `src/utils.test.ts`)

## Build notes

- `vite.config.ts` externalizes `react` and `react-dom`; builds ESM only (no UMD)
- Types generated by `unplugin-dts` into `dist/lib/index.d.ts`
- `"files": ["dist"]` in package.json — only `dist/` ships to npm

## Testing

- Tests in `src/lib/Slider.test.tsx` (snapshot, keyboard, drag/threshold, rAF-cancel) and `src/utils.test.ts`
- Vitest configured inline in `vite.config.ts` with `jsdom` environment

## Gotchas

- React peer dep is `>=18.0.0`
- No CI workflow exists (`.github/` only has `FUNDING.yml`)
