# Scale on drag

The `scaleOnDrag` prop adds a scale animation while a slide is being dragged:

<ExampleScaleOnDrag client:load />

```jsx
<Slider scaleOnDrag>
  {images.map(({ url, title }) => (
    <img src={url} key={title} alt={title} />
  ))}
</Slider>
```
