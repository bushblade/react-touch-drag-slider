# Transition

The `transition` prop sets the duration, in seconds, of the snap animation. The
default is `0.3`.

This example uses `transition={0.8}` — a slower, more noticeable snap:

<ExampleTransition client:load />

```jsx
<Slider transition={0.8}>
  {images.map(({ url, title }) => (
    <img src={url} key={title} alt={title} />
  ))}
</Slider>
```
